Welcome to MyLastArch

MyLastArch 2026.11.01 for Raspberry Pi 4 and Pi 400 is based on Arch Linux ARM and includes a configured KDE Plasma desktop.

Important security step: this image ships with public default passwords. Change both passwords immediately after your first login.

Default Login

UsernamedefaultUser passworddefaultRoot passwordroot

Change the user password:

passwd

Change the root password:

sudo passwd root

Direct root login over SSH is disabled.

First Steps

  • Select the correct time zone when System Settings opens.
  • Connect with Plasma's network icon.
  • The root filesystem expands automatically on first boot.
  • Use Ark to open and create archives.
  • Manage the enabled Firewalld service in System Settings.

Safe Updates

MyLastArch follows Arch Linux ARM's rolling repositories. Always perform a complete system upgrade:

sudo pacman -Syu

Avoid running pacman -Sy by itself. Arch Update is also available from the system tray.
